# Fundamentals of Computing – Team Website

A student team website created for the Fundamentals of Computing course. The website introduces the course, presents the project team, shares course video presentations, provides project documentation, and demonstrates a JavaScript To-Do List application.

## Website Sections

1. **Home / Cover Page** – Course description and team mission.
2. **Our Team** – Team member biographies and photos.
3. **Video Gallery** – Links to each member's course presentation videos.
4. **Documentation** – Links to the written report, presentation slides, and supporting evidence.
5. **To-Do App** – An interactive task list demonstrating adding, completing, deleting, and saving tasks with browser `localStorage`.

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser localStorage
- GitHub Pages

## Run Locally

Download or clone this repository, then open `index.html` in a web browser. For a more reliable local development experience, use the Live Server extension in Visual Studio Code.

## Publish with GitHub Pages

1. Create a **public** repository on GitHub.
2. Upload all files and folders from this project. Keep `index.html` in the repository root.
3. Open the repository's **Settings**.
4. Select **Pages** from the left sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish the site. The live URL will look like:

   `https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

8. Replace the placeholder URL in this README with the actual published URL.

## Notes

The To-Do List stores tasks in the browser's localStorage. Tasks remain after refreshing the page in the same browser on the same device, but they are not synchronized between devices and may be cleared if browser site data is removed.
